# Pedestrian Crossing Simulation

## Description

The phenomenon I chose to observe is that, when there is a crosswalk drawn on the ground, people do not always wait for the walk signal before crossing. I want to explore how pedestrians decide when to cross the street, what factors seem to influence that decision, and whether there are noticeable patterns in this process.

## Files

- `index.html` — the complete simulation, including HTML, CSS, and JavaScript.
- `README.md` — project description and instructions.

## Install and run

No package installation, build step, or local server is required. Open `index.html` in a modern web browser.

### Download ZIP

1. Open [Activity-Represent-a-Phenomenon on GitHub](https://github.com/RuiqiiLiu/Activity-Represent-a-Phenomenon).
2. Click **Code → Download ZIP**.
3. Extract the ZIP. On Windows, right-click it and select **Extract All**; on macOS, double-click it.
4. Open the extracted folder and double-click `index.html`, or use **Open with → your web browser**.

### Clone with Git

With Git installed, run:

```sh
git clone https://github.com/RuiqiiLiu/Activity-Represent-a-Phenomenon.git
cd Activity-Represent-a-Phenomenon
```
Then open `index.html` in your browser. 

To download later updates, run `git pull` inside the cloned folder after committing or otherwise saving any local changes.
